# BS Vision X

ESP box + linee traccianti + distanza, aimbot predittivo, auto-dodge, auto-super.
Lavora solo su framebuffer e eventi HID: nessuna scrittura in memoria, undetectable.

## Build
Actions -> build -> Run workflow -> scarica l'artifact BSVX-deb.
Contiene due deb: rootless (Dopamine, palera1n rootless) e rootful.

## Install
Apri il deb giusto con Sileo -> respring.

## Primo avvio
Entra in un match, metti un nemico sul bordo del cerchio di range, premi CALIBRA RANGE.
Va rifatto per ogni brawler.
